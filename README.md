# evrowd

My first GitHub repository. 👋

## What is in here

- `index.html` is a small web page that says "Hello Jin Yi".
- `petty-cash.html` is a petty cash tracker. Staff claims go in, and the page adds up the totals.
- `README.md` is this note. GitHub shows it on the front page of the repository.

## Three words to know

- **Repository**: a folder that lives on GitHub. It keeps your files, and it remembers every change ever made to them.
- **Commit**: one saved change, with a short note saying what changed. Like a save point in a game.
- **Pull request**: a suggested change. Someone proposes it, you look at it, and you press **Merge** to accept it.

## How to see the page

Open `index.html` on GitHub, then press **Raw** or download it and open it in your web browser.

## Petty Cash Tracker

Open `petty-cash.html` in a web browser (on your PC or phone).

1. Type this month's float, for example 1000.
2. Add each claim: date, staff name, category, description and amount in RM.
3. The page shows the total, the cash left, and totals by staff and by category.
4. Press **Download for Excel** to get a file that opens in Excel.
5. Press **Print** to print the month, with lines to sign at the bottom.

The claims are saved in the browser on that device only. Press **Download backup** now and then to keep a copy.
